DAILY STRETCH — GITHUB PAGES

Upload index.html, manifest.webmanifest, service-worker.js, icon-192.png, icon-512.png, and apple-touch-icon.png to the ROOT of your daily-stretch repository. README.txt is optional.

On GitHub: Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.

Visit https://natewido.github.io/daily-stretch/ in iPhone Safari. Use Share > Add to Home Screen > Open as Web App > Add.

After opening once while online and allowing the site to load fully, the service worker should make the app available offline. Test in Airplane Mode before relying on offline use.

Version 14 remains the untouched original; this is a separate installation package.
